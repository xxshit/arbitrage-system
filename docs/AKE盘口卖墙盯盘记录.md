# AKE 盘口卖墙盯盘记录

## 用户新思路

AKE 在盘口上方出现重点卖墙/压力带：

- 0.0020 附近：约 1.1M AKE 卖单
- 0.0021 附近：约 1.2M AKE 卖单
- 0.0022 附近：约 1.0M AKE 卖单
- 重点压力带：0.0020–0.0023

用户的两个假设：

1. 如果主力主动把价格拉到 0.0020–0.0022 以上，说明愿意吃掉或逼退这部分压力，后续可能继续拉盘，把上方做空/卖压爆掉或逼走。
2. 如果价格一直站不上 0.0020，则可能在 0.0020 下方开始派发，随后转为下跌。

## 我的补充判断

盘口挂单不能直接等同真实空单，因为挂单可以撤，也可能是诱导盘口。但它可以作为“主力是否愿意吃墙”的观察线索。

因此 AKE 卖墙盯盘必须结合：

- 是否站上 0.0020；
- 是否进一步站上 0.0022；
- 突破时 CVD 是否继续上涨；
- 持仓是否没有同步塌掉；
- 成交量是否放大；
- 基差是否继续正向打开；
- 是否出现空头爆仓跟随。

## 盯盘规则

### LARK 推送降噪规则

AKE 盘口墙属于“方向确认前的观察信息”，不能因为正资费、正基差、普通多头结构就频繁推送。

从 2026-07-18 起，AKE LARK 推送只保留三类更明确的信号：

- 卖墙突破：价格站上 0.0022，且 CVD/持仓配合；
- 墙下派发：价格站不上 0.0020，且量能活跃、价格或 CVD 转弱；
- 出货警报：放量、资金费率转负、基差明显打开同时出现。

普通“正资费 + 正基差 + 合约量大”的多头观察，只在网页里显示，不再自动推送 LARK。

AKE 不设置固定冷却时间。机会来了必须立刻通知。

推送逻辑改为“状态变化即时推送”：

- 试探 0.0020；
- 进入 0.0020–0.0022 卖墙区：必须提醒；
- 突破 0.0022 上沿：必须提醒，归类为强势上涨/逼空走势；
- 插上 0.0020 后快速回踩：作为当前 AKE 假设观察，不直接视为失败，也不作为固定知识点；
- 反复试探 0.0020 失败后跌回 0.00195 下方并转弱。

同一个完全相同的状态与价格桶不重复推；但只要进入新状态，或价格推进到新的关键区间，就必须立刻推送。

### 当前 AKE 剧本假设：拉升吸空后换手

用户思路（待验证，不作为固定知识点）：

AKE 向上插针到 0.002 以上后立刻回调，不应直接理解为上攻失败。因为 0.002 是盘口重点墙区下沿，一旦插上去，很多空单挂单和追空心理会被激活。主力不一定马上砸盘，反而可能先诱导空单进场，随后继续上涨。

2026-07-18 追加用户剧本：

主力把币价拉得很猛，用户推测主力手上已经握有大量多单。主力如果要平多盈利，需要空头对手盘承接；如果没有足够空单，多单很难顺利平出去。因此用户认为主力可能开始吸引空单进场：

- 可能走几波小幅向上的来回波动，让空头不断进场；
- 也可能直接插上 0.0022，把空单和卖墙一起吃进来；
- 随后进入大量换手阶段。

该剧本目前只作为 AKE 当前盘面假设，后续需要通过价格、持仓、多空人数比、CVD、资金费、基差和成交量验证。

盯盘验证方式：

- 只要最近高点/压力位触及过 0.0020；
- 当前回踩仍在 0.00192–0.0020 区间；
- 持仓没有塌、CVD 没有连续恶化，或量能没有形成放量下杀；
- 临时标记为“插针回踩 / 诱空假设观察”，继续盯后面是否重新站上 0.0020。

验证成功条件：

- 回踩后重新站上 0.0020；
- 进一步进入 0.0020–0.0022 区间；
- 若站上 0.0022，则说明用户假设更可能成立，归类为强势上涨/逼空走势。
- 进入 0.0020–0.0022 后，如果出现多次小波动但低点逐步抬高、持仓不塌、资金费/基差仍支持合约端溢价，则“吸空后继续拉”的假设增强。
- 若 0.0022 上方放量冲高后出现持仓快速掉落、CVD 背离、资金费转负或基差异常反向打开，则进入“大量换手/出货验证”。

证伪/降级条件：

- 跌破 0.00190；
- 价格、CVD 连续转弱；
- 持仓不再增加甚至同步转弱；
- 则把它从诱空假设降级为墙下失败。

### 卖墙突破 / 逼空观察

触发倾向：

- AKE 价格进入 0.0020–0.0022 区间，就已经进入卖墙战场，必须推送；
- AKE 价格进一步站上 0.0022，归类为强势上涨/逼空走势，必须推送；
- CVD、持仓、量能只作为推送中的辅助判断，不再作为触发提醒的必要条件；
- 0.0020–0.0023 压力带仍作为重点参考墙区。

解释：

如果主力愿意把价格推进到 0.0020 上方，说明已经开始进入压力区，必须提醒。0.0022 是上沿强势确认，站上后按强势上涨/逼空走势提醒。

### 墙下派发 / 转弱观察

触发倾向：

- AKE 必须先接近或试探过 0.0020 压力带，不能离压力带还远就误判失败；
- 随后价格跌回 0.00195 下方；
- 30MIN/1H/2H 中，价格和 CVD 都至少两个窗口转弱；
- 成交量出现活跃但价格无法突破。

解释：

如果主力不吃墙，墙本身就不是“必然逼空目标”，而可能变成出货天花板。

## 系统实现备注

Binance 合约 depth API 只返回有限档位。当前价离 0.0020 较远时，1000 档公开深度可能覆盖不到 0.0020–0.0023，因此系统区分两类数据：

- 实时可见盘口墙：API 深度覆盖到墙区时使用；
- 用户观察参考墙区：API 暂时覆盖不到时，只作为重点价位参考，不假装为实时挂单。

## 2026-07-24 资金面结构修正：CVD上涨不等于继续看涨

用户纠正：

AKE 已经离开最初的 0.0020-0.0022 旧墙区后，不能继续只盯价格区间。必须结合持仓、多空人数比、CVD、资费和基差一起判断。

本次新增判断：

- 如果 `CVD上涨`，但同时 `持仓下降 + 多空人数比上升`，不能继续简单理解为主力扫货。
- 这类资金面更接近：散户平空、主力平多。
- 对 AKE 这种高位大涨币，这代表看涨信息减弱，甚至进入高位换手/派发观察。
- 如果同时 `BN资费转负 + BN基差转负`，说明合约端从“拉高合约吸引空单”逐步转向“高位换手或多头减仓”。

新的 AKE 推送要求：

1. 不再只写 0.0020-0.0022 区间；
2. 必须说明当前看涨信息是增强还是减弱；
3. 必须解释资金面结构：持仓、人数比、CVD、资费、基差之间是否共振；
4. 若出现 `持仓下降 + 多空人数比上升`，即使 CVD 仍上涨，也优先标记为“主力平多观察 / 看涨减弱”；
5. 后续只有当持仓重新增加、人数比回落、资费/基差修复，才恢复看涨增强。

## 深度档位限制

- BN U 本位合约公开 REST 深度接口最大为 1000 档，系统已使用最大档。
- BN 现货公开 REST 深度接口最大为 5000 档，系统会尝试作为辅助卖压参考；如果该币没有 BN 现货或接口不返回，则不参与判断。
- 用户在 BN 网页端看到的更远深度，可能来自网页聚合档位或内部前端数据，不一定能通过公开合约 REST API 直接拿到。

## 2026-07-24 旧卖墙剧本复盘：没有完全验证，切换为新区间观察

用户问题：

AKE 后续走势好像和原先预想的不一样，是否说明我们的想法没有被验证。

本次快照：

- 最新价约 `0.0026954`；
- 24H 涨幅约 `+31.19%`；
- 近 30M：价格约 `-1.27%`，CVD 为负；
- 近 1H：价格约 `-3.61%`，持仓约 `-1.90%`，多空人数比约 `+2.24%`，CVD 为负；
- 近 2H：价格约 `-6.45%`，持仓约 `-10.07%`，多空人数比小幅上升，CVD 为正；
- 近 4H：价格约 `+13.12%`，持仓约 `+5.57%`，CVD 为正；
- 近 12H / 24H：价格仍明显上涨，但持仓相对下降，人数比回升；
- Binance 资费约 `+0.005%`，接近低保；
- Binance 基差约 `-0.1766%`，已经不是原先明显正基差拉高合约的结构。

结论：

旧的 `0.0020-0.0022 卖墙 / 吸空 / 逼空` 剧本并没有被完整验证。价格确实进入并突破过墙区，也继续创出更高区间，这说明“不能在 0.002 以下简单看失败”是对的；但后续资金面没有持续给出强验证：

- 近端持仓明显回落；
- 多空人数比开始回升；
- 基差从正向保护变成轻微负基差；
- 资金费回到低保附近；
- 近 30M / 1H CVD 转弱。

因此不能继续机械复读“还在吃墙逼空”。当前更合理的描述是：

> AKE 已经离开旧墙区，进入高位新区间。趋势没有完全走坏，但原先的强逼空假设被削弱，需要切换为“高位换手 / 新区间确认”观察。

新的观察区间：

- 下方关键：`0.0022-0.0024`，观察旧压力是否变成支撑；
- 当前中枢：`0.0024-0.0027`；
- 上方压力：`0.0028-0.0029`，若放量突破且持仓重新增加、人数比重新下降，才恢复看涨增强；
- 若跌回 `0.0022` 下方，并且 CVD 继续为负、持仓继续下降，则说明旧墙区突破更可能只是高位换手后的回落。

后续推送修正：

- 不再只盯 `0.0020-0.0022`；
- 必须写清楚“看涨增强 / 看涨减弱 / 高位换手 / 新区间等待确认”；
- 如果只是价格小幅变化、判断没有新意，4H 内不重复推送；
- 只有资金面结构出现新变化，才再次提醒。
