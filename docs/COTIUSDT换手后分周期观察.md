## 我的独立判断

用户的中长线偏空假设有逻辑基础，但目前证据更适合定义为“高风险换手期”，不能直接定义为“已经出货完成”。

结算周期缩短说明合约端出现异常失衡和风险控制调整，但它不是主力完成换手的单独证据。极负基差、极负资费也不能直接定义为空头拥挤；它可能来自空头压力，也可能来自主力拉高现货、控制合约价格形成贴水，以吸引多头继续推动现货或为换手准备对手盘。若 CVD 下跌但价格抗跌，同时持仓增加、人数比下降，主动卖盘可能正在被被动买盘吸收，短线也存在逼空风险。

因此必须分周期：

- 短线（5MIN-4H）：中性偏强观察。偏多犄角未破坏前，不追空。
- 波段（1D-3D）：偏空观察。等待价格跌破换手区低点、反抽失败，并与 CVD 继续走低及犄角破坏共振。
- 中长线（1W+）：保留看空假设，但还需持续派发、仓位结构和官方供给/解锁信息补证。

## 验证与推翻条件

### 看空升级

1. 价格由“负 CVD 下抗跌”转为跌破结构低点，并且反抽失败。
2. 持仓和人数比的偏多犄角被破坏。
3. CVD 继续下降，且价格不再被有效承接。
4. 负基差、负资费持续存在时，价格开始同步走弱，而不是逆势上涨。

### 看空降级或推翻

1. 价格在 CVD 继续为负时仍不断抬高低点。
2. 持仓增加、人数比继续下降，偏多犄角延续。
3. 负基差和负资费逐步修复，价格放量突破换手区高点并回踩不破。
4. CVD 由负转正，主动买入重新接管。

## 两种“反犄角”空头路径

- 价格下跌、持仓下降、人数比回升、CVD 下跌：更像多头撤退或平多派发。
- 价格下跌、持仓增加、人数比回升、CVD 下跌：更像新空建立。

两种结构都偏空，但第一种容易在集中平仓后快速反抽，第二种更可能形成持续下跌；以后不能混在一起判断。

## 后续复盘任务

- 核对短线偏多犄角最终是延续逼空，还是先于价格破坏。
- 核对极负资金面究竟是出货换手、拥挤空头逼空、现货主导拉盘，还是人为控制合约贴水以吸引多头。
- 分别统计短线、波段、中长线判断结果，不用一个方向覆盖所有周期。

## 2026-07-30 负基差、负资费竞争假设

负基差、负资费只确认“现货价格相对合约更强、合约端资金费为负”，不能直接确认参与者拥挤方向或主力意图。COTI后续至少同时保留四条假设：

1. **拥挤空头/逼空燃料**：价格抗跌，OI增加、人数比下降；随后合约快速追上现货、基差收敛，伴随空单清算。
2. **现货主导拉盘、合约受控**：现货价格与主动买入先动，合约滞后，负基差扩大；主力可能借现货抬价，同时压住合约避免过早过热。
3. **吸引多头抬价**：负资费为做多者提供收益预期，人数比与OI回升，但合约价格仍被压制；若现货继续上行，说明多头正在成为抬价和接盘力量。
4. **换手/派发**：现货放量但价格推进减弱，OI下降后重建，CVD和人数比反复，负基差持续或加深；最终价格失守承接区且反抽失败。

验证顺序：先看现货和合约谁领先，再看两端成交量与主动成交，随后看OI、人数比、CVD和清算，最后观察基差以“合约追涨、现货回落或两端共同下跌”的哪种方式收敛。只有路径证据连续出现，才提高对应假设权重。
