# HEI/USDT 链上转币风险盯盘记录

更新时间：2026-08-06（UTC+8）

## 用户假设

- 用户观察到链上地址向交易所转入 HEI，担心相关持币方可能准备出货。
- 地址归属、转账目的和后续卖出行为尚未由系统独立核验，因此该观察只作为风险假设，不能写成“主力已经出货”的事实。

## Codex 独立观点

- 向交易所转币会提高潜在可售供给，值得提高监控频率，但也可能是做市调仓、托管迁移、抵押或内部归集。
- 是否进入派发阶段，应继续用基差、5MIN 价格、成交量/CVD、持仓和多空人数比共同验证。单一转账或单根下跌都不足以确认主力行为。

- 以上只是带时间戳的验证样本，不代表后续固定价格、固定趋势或固定出货结论。

## 专属触发规则

- HEI 在盯盘名单启用时每 30 秒复核一次；普通盯盘仍按原 5 分钟周期运行。
- 单根 5MIN 跌幅达到 `-3%`，或 15MIN 累计跌幅达到 `-7%`，推送急跌风险。
- 单根 5MIN 涨幅达到 `+4%`，或 15MIN 累计涨幅达到 `+7%`，推送急涨/冲高换手风险。
- 5MIN 或 15MIN 成交额达到近期同长度均值 `2.5 倍`，按 CVD 正负分别推送主动买入或主动卖出量能异动。
- BN 基差低于 `-0.30%` 或高于 `+0.30%` 时进入基差异常区，并按 `0.30/0.60/1.00/2.00%` 深度分区去重。
- 同一根 5MIN K线的同类异常只推一次；基差未进入新风险区间时不重复推送。

## 验证与失效条件

- 支持出货风险：急跌或放量滞涨同时伴随卖出 CVD、持仓退出或新增空仓、人数比追多、基差继续走弱。
- 反证：放量上涨由主动买入推动，币本位持仓增加、人数比不过热，且基差修复或维持健康；此时不能把转币假设继续当作主叙事。
- 推送只报告异常与证据变化，不构成做空指令或收益承诺。
