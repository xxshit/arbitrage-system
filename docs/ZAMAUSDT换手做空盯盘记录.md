- 转空必须新增证据：CVD转弱、持仓退出、人数比追多或异常放量，且价格跌破近端低点后反抽无法收回。

## 触发顺序

1. 基差连续两次30秒快照为负：提醒换手观察。
2. 资费跟随转负：换手证据增加，不要求低于固定数值。
3. 价格滞涨、CVD转弱，并伴随持仓退出、人数比追多或异常放量：做空确认观察。
4. 跌破近端结构低点且反抽无法收回：价格确认增强。
5. 若价格、CVD和持仓继续共振上涨：做空假设降级，先防主升或逼空延续。
