## 访问方式

本机双击项目根目录的`打开云端网站.vbs`，会隐藏建立SSH隧道并打开：

`http://127.0.0.1:5000`

也可以手动执行：

```powershell
ssh -N -i "$env:USERPROFILE\.ssh\arbitrage_deploy_5_61_208_92" -p 16206 `
  -o BatchMode=yes -o ServerAliveInterval=60 -o ServerAliveCountMax=3 `
  -L 127.0.0.1:5000:127.0.0.1:15831 root@5.61.208.92
```

网站、数据库和后台采集始终在云端运行。本机SSH隧道只负责访问，关闭电脑不会停止云端任务。

## 运维命令

```bash
pm2 status arbitrage-private
pm2 status arbitrage-db-backup
pm2 restart arbitrage-private
pm2 logs arbitrage-private --lines 100
pm2 logs arbitrage-db-backup --lines 100
curl -I http://127.0.0.1:15831/login
```

数据库和环境密码不得写入Git、文档或聊天记录。部署密钥私钥仅保存在Windows个人SSH目录，不在项目仓库中。

## 资源安全结论

预热后容器内存约3.48GB/4GB，新应用Gunicorn主进程与worker合计约210MB，OOM计数没有增加。余量仍然偏薄，后续增加大型任务前必须重新检查`memory.current`和`memory.events`；如果发生新OOM，应优先停止`arbitrage-private`并分析，而不是影响原有项目。
