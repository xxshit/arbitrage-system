日常使用优先打开公网HTTPS地址：

`https://arbi-k7m4p2.5-61-208-92.sslip.io:18443/`

公网入口只反向代理网站，不开放Gunicorn或MySQL。下面的SSH隧道保留为维护和公网入口故障时的备用通道。

本机双击项目根目录的`打开云端网站.vbs`，会隐藏建立SSH隧道并打开：

`http://127.0.0.1:5000`

也可以手动执行：

```powershell
ssh -N -i "$env:USERPROFILE\.ssh\arbitrage_deploy_5_61_208_92" -p 16206 `
  -o BatchMode=yes -o ServerAliveInterval=60 -o ServerAliveCountMax=3 `
  -L 127.0.0.1:5000:127.0.0.1:15831 root@5.61.208.92
```

网站、数据库和后台采集始终在云端运行。本机SSH隧道只负责访问，关闭电脑不会停止云端任务。

## 2026-08-03 聊天短暂断线修正

- 事实：协作记录启用1秒增量读取后，Gunicorn的`--max-requests 500`会很快触发worker回收；服务只有一个worker，回收交接期间没有第二个worker承接请求，浏览器可能出现`Failed to fetch`。
- 修正：保持单worker、4线程，移除按500次请求自动回收的参数，避免复制后台采集和Lark推送任务；继续保留PM2的420MB内存重启保护。
- 前端保护：联系人和消息读取遇到短暂断线时自动重试；发送连接中断时不再弹出原始英文错误，而是保留输入内容、自动核对发送结果，并用页面状态提示用户确认。
