# 交易对别名库

更新时间：2026-08-06

## 目的

不同交易所可能把同一个标的用不同名字展示，尤其是倍率合约，例如：

- 标准现货标的：`XEC/USDT`
- 合约交易对：`1000XEC/USDT`

如果不把它们关联起来，搜索、现多期空、期多期空、涨跌幅榜、详情弹窗都会把它们当成两个不同的币，导致漏搜或重复展示。

## 数据库表

新增表：`symbol_alias`

核心字段：

- `canonical_symbol`：标准交易对，例如 `XEC/USDT`
- `alias_symbol`：交易所实际显示或合约显示的名字，例如 `1000XEC/USDT`
- `canonical_base`：标准币名，例如 `XEC`
- `alias_base`：别名币名，例如 `1000XEC`
- `exchange`：适用交易所，通用填 `ANY`
- `market_type`：现货、合约或通用场景
- `multiplier`：倍率，例如 `1000`
- `verified`：是否已经确认是同一标的
- `note`：确认依据

## 当前已确认

| 标准标的 | 别名 | 适用范围 | 倍率 | 说明 |
| --- | --- | --- | ---: | --- |
| `XEC/USDT` | `1000XEC/USDT` | 全部交易所合约 | `1000` | 1 张 1000XEC 合约对应 1000 枚 XEC 标的 |
| `PLAY/USDT` | `PLAYSOUT/USDT` | Bybit 合约 | `1` | Binance 使用 `PLAYUSDT`；Bybit 使用 `PLAYSOUTUSDT` |
| `SKYAI/USDT` | `SKYAI1/USDT` | Bybit 合约 | `1` | Binance 使用 `SKYAIUSDT`；Bybit 使用 `SKYAI1USDT` |

## 2026-08-06 核验记录

- 用户观点：`PLAY` 与 `PLAYSOUT` 是同一币，`SKYAI` 与 `SKYAI1` 是同一币，判断依据是官网地址相同。
- 公开资料验证：Binance 合约公开接口当前返回 `PLAYUSDT`、`SKYAIUSDT`；Bybit 合约公开接口当前返回 `PLAYSOUTUSDT`、`SKYAI1USDT`。
- 官方资料验证：Bybit 的 `PLAYSOUTUSDT` 上币公告将标的写为 PlaysOut、官网写为 `https://www.playsout.com/`；`SKYAI1USDT` 上币公告将标的写为 SKYAI、官网写为 `https://skyai.pro/`。
- 行情验证：核验时两组 Binance 与 Bybit 买卖价处于同一数量级并紧密同步，倍率均按 `1` 处理；实时价格只作交叉验证，不单独作为同币证明。
- 结论：两组关系已由用户判断、交易所代码、官方项目标注和实时价格共同验证，可作为已确认交易对别名写入系统；若交易所后续换币、迁移合约或重新使用旧代码，需要重新核验，不能永久假定。
- 官方来源：[Bybit PLAYSOUTUSDT 上币公告](https://announcements.bybit.com/en/article/new-listing-playsoutusdt-perpetual-contract-in-innovation-zone-with-up-to-25x-leverage-blt560e07485c8518c6/)、[Bybit SKYAI1USDT 上币公告](https://announcements.bybit.com/en/article/new-listing-skyai1usdt-perpetual-contract-with-up-to-10x-leverage-bltc390d2afccc10cf8/)。

## 使用规则

- 搜索 `XEC` 时，需要同时匹配 `XEC/USDT` 与 `1000XEC/USDT`。
- 搜索 `1000XEC` 时，也要能反向找到同一组标的。
- 现多期空和期多期空不能只看页面显示名称，要先过别名库。
- 运行规则页提供“同币异名配对”：管理员可以添加和删除手工记录，普通账号只读；内置核验记录不能从网页删除。
- 手工添加时必须选择别名实际出现的交易所和市场类型；不确定范围时不能为了方便随意选择“全部交易所”。
- 倍率为 `1` 表示同单位报价；`1000XEC` 这类倍率合约必须填写真实倍率，系统会先换算到标准单位再比较价格。
- 保存、删除别名后会清理行情缓存，下一轮行情刷新按新关系计算；数据库别名快照最多缓存 30 秒。
- 不能仅靠名字相似自动合并，必须确认是同一个标的后再写入表。
- 后续遇到 `1000PEPE`、`1000SATS`、`1000BONK` 等类似情况，按同样方式入库。
