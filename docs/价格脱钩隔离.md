## 判定与恢复

每轮新鲜现多期空行情进入普通报警前检查；网页GET只读数据库。需有完整有效正价格、非交叉盘口及真实币安标记/指数，同时满足：

1. 开差与平差同方向，两者差距小于0.6个百分点；币安标记/指数基差绝对值不超过1%，合约盘口中间价/指数偏离不超过2%。这样不能仅凭标记基差小，把合约盘口自身的大幅偏离误判为现货脱钩。
2. 该现货所存在新鲜、明确关充或关提链：开/平差绝对值均至少5%，连续5分钟确认。充提未知或无明确关闭证据：两者均至少10%，连续15分钟确认。正负方向对称，充提过期不作关闭证据，单独关充提不触发隔离。
3. 首次符合先显示“疑似脱钩”并暂停该路径报警；达到时间及至少3次连续观察后显示“价格脱钩”。报价缺失/无效、方向变化或超过30秒采样间隔会重置待确认计时；已经隔离的路径继续隔离，保留原报价时间并显示待更新。
4. 只有有效开差和平差绝对值均小于2%，连续2分钟，才恢复新报警。中间缺数据、恢复失败均重新计时；状态写MySQL，重启不能自动恢复。持续偏离阈值是风险筛选规则，不宣称已识别经济学原因，也不能保证覆盖所有小幅脱钩。
