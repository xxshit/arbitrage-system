# 多电脑私密访问

网站继续只监听云服务器的`127.0.0.1:15831`，不开放公网网站端口。每台电脑通过现有SSH端口建立私密通道，再在本机打开`http://127.0.0.1:5000`。

## 为什么不直接开放端口

- 不向互联网暴露登录页和应用指纹；
- 数据在SSH加密通道内传输；
- 每台电脑使用独立密钥，丢失时可以单独撤销；
- 专用账户`arbtunnel`只能转发到网站，不能登录服务器执行命令，也没有root权限。

## 新电脑接入

1. 下载项目代码并安装Windows“OpenSSH 客户端”。
2. 在项目目录执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\create_private_access_key.ps1
   ```

3. 只把生成的`.pub`公钥内容交给服务器管理员登记，绝对不要发送没有`.pub`后缀的私钥。
4. 复制`cloud-access.example.json`为`cloud-access.local.json`，填写服务器地址、SSH端口和本机私钥路径。此文件已被Git忽略。
5. 双击`打开云端网站.vbs`。

网站本身仍使用各自的网站账号登录。SSH访问密钥只负责建立网络通道，不能代替网站账号。

服务器管理员登记公钥时使用`authorize_tunnel_key.sh`。脚本只接受Ed25519公钥，并自动限制该密钥只能转发到网站的私有监听端口。

## 撤销电脑

删除该电脑对应的服务器公钥行即可立即撤销通道权限，不需要更换其他电脑的密钥，也不影响网站运行。
