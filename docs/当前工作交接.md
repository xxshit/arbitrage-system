## 已知边界

- 设备指纹是当前浏览器/PWA的加密身份，不是硬件序列号。清除网站数据、换浏览器或重装主屏网页会丢失私钥，需要管理员通过站外方式核实本人后解除旧绑定；已控制原电脑或浏览器资料的攻击者不在该机制可防范围内。
- 行情和趋势判断必须区分用户假设、Codex 假设、验证结果与被推翻结论；未经验证不能升级为固定知识。
- 趋势推送必须出现新的结构、数据变化或观点变化；同结构同判断不得机械重复推送。
- 本地网站当前按用户要求保持停用；这不影响本地 MySQL 备份与同步。
