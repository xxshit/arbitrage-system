## 已知边界

- 设备指纹是当前浏览器/PWA的加密身份，不是硬件序列号。清除网站数据、换浏览器或重装主屏网页会丢失私钥，需要管理员通过站外方式核实本人后解除旧绑定；已控制原电脑或浏览器资料的攻击者不在该机制可防范围内。
- 行情和趋势判断必须区分用户假设、Codex 假设、验证结果与被推翻结论；未经验证不能升级为固定知识。
- 趋势推送必须出现新的结构、数据变化或观点变化；同结构同判断不得机械重复推送。
- 本地网站当前按用户要求保持停用；这不影响本地 MySQL 备份与同步。
- iPhone主屏Web Push代码和云端VAPID P-256运行配置均已启用；当前剩余真实设备授权与端到端收件验证。iOS/iPadOS需为16.4或更高版本，必须从Safari添加到主屏幕、从主屏图标打开并由用户手势点击“开启通知”。静音/专注模式、系统通知设置和Push服务延迟仍可能导致不响或延迟。
- 登录 IP 是安全审计线索，不是设备唯一标识。NAT、共享网络、VPN、移动网络和 IPv6 前缀变化都可能改变 IP；设备准入仍以 P-256 浏览器/PWA身份为准。IP归属地只能近似到国家/省州/城市/邮编和网络机构，不能可靠定位街道、住宅或门牌，VPN/代理只能显示出口节点。历史已有IP会在管理员打开审计页时尽力补齐，无法查询时保持“待更新”。
- BMT 在旧 `50%` 规则下没有构成漏推；门槛下调为 `40%` 后，其历史最强窗口按新规则可成立，但系统不补推已经离开最新窗口的旧行情。后续只对最新五根已收盘30MIN结构判断和推送。
