# 我的套利思维：现多期空候选分级

## 范围与事实边界（2026-10-21）

用户最后澄清：保留“现多期空／期多期空”的策略框架，不把栏目改成“资费型／价差型／双重型”。本轮仅为已经讨论的现多期空建立分级；资金费、价差及两者兼有是入选依据。期多期空沿用原有筛选，不擅自套用本规则。美股继续独立。

“主力通过资费吸引套利盘、派发现货，或通过空头和资费对冲下跌”是用户提出的解释假设，不是可由公开盘口证明的事实。本模块不据此给币种贴“主力正在做市/出货”标签，只提供可复核的费率、价格变化、价差和盘口证据。

资费基准按每日 0.03% 折算：4H 为 0.005%，8H 为 0.01%，1H 为 0.00125%。它是比较基准，不是保底或交易所费率下限。实际费率可能为负，预计费率不等于结算结果。参考：[Binance 官方资金费说明](https://www.binance.com/en/support/faq/detail/360033525031)。

## 入选与分级

- 资费改善或价差潜力二者满足其一即可，不再要求“正开差 AND 正资费”。
- 本期预计资费高于对应周期基准，或者最近12小时出现过高于基准的实际结算，且最近一期及已采24H合计为正，进入资费观察。此前全是基准不阻止新改善入选。
- 价格上升、回撤均不作为硬性剔除条件，走势仅作辅助说明。
- 同路径近期有效开差振幅 ≥0.40%、绝对峰值 ≥1%，进入活跃价差观察。负开差不能取绝对值当正向利润。
- 当前正开差 ≥0.30% 保留观察；若已采区间振幅 ≤0.15%、资费没有改善，降为 C，不假定会收敛到零。
- 已确认／待确认的脱钩仅排除对应交易路径；同币其他交易所路径独立计算。近期下架证据按交易所和现货/合约范围核验，不用一个全币警示排除所有路径。

| 等级 | 含义 |
| --- | --- |
| A · 优先 | 当前盘口及质量条件通过，净空间情景 ≥0.30%，优先人工复核 |
| B · 关注 | 资费改善、价差活跃，或当前净空间情景 ≥0.10% |
| C · 低优先观察 | 固定溢价、低资费，或盘口不可用／充提受限 |

状态独立于等级：`当前有机会` 仍只是满足配置条件的研究候选；其余为 `值得观察`。不输出胜率或保证收益。没有足够平差历史时暂不产生当前机会，不制造 A 级数量。

## 当前状态与测算

默认现货参考金额 1000 USDT，持有情景3天，可选1/3/7天，金额100–1000000 USDT。不是实际下单参数，不创建订单。

1. 实时两腿买一卖一来源于已有公开报价 Hub；每腿不超过4秒、偏差不超过2秒，价格不交叉。按已核验合约倍率统一价格和数量单位。
2. 同币等数量；四个首档数量的最小值只取50%，折成现货金额。未知数量不当作零或者无限容量。容量不足只观察。
3. 通道未知、受限、过期不当正常；元数据超过60秒、资费报价超过600秒不作当前机会。
4. 平差参考为同路径近24H有效5分钟末值的75分位，负平差利好按零处理，再留10%余量。至少1小时跨度、12个5分钟格、跨度内≥50%格有数据、末值5分钟内，后台汇总6分钟内才可用。
5. 退出时现货价格假定不变，净价差空间为当前开差减退出平差预算、四笔交易费用、滑点和不利资费。单次现货费用预算0.20%、合约0.10%，按相同标的数量和合约/现货价格比折算，并额外预留10%；滑点预算0.10%。不是用户账户真实费率。
6. 正资费情景取“当前费率按日归一”与“真实已结算24H带符号累计”的较低值，再乘0.5并按持有期折算。不能延续一次突然高费率；负资费按持有期包含边界的一期追加预算。资费不利时不使用正收入掩盖。
7. 结算历史缺口、周期无法推断时不计正资费收入，但不否决独立通过的价差机会。相邻实际结算间隔推断周期；缺失不能解释为低保，变更期间保守降低完整性。

平差分位是退出**假设**，不是已完成的开仓→平仓回测，不是历史最大开差减最小平差的“可实现收益”。波动、真实费率、持有期限、滑点、基差风险、稳定币与通道风险均可能改变实际结果。

## 历史采集、性能和资源边界

- `spread_history.py` 增加 `close` 指标，沿用约5秒有效采样、每分钟首/末/极值及断档分段，15天日分片与检查点。原开差和基差历史保留，不补造旧平差。
- `opportunity_history.py` 增加 `book` 指标：每5分钟保留第一份有效双腿同步首档快照（买一/卖一、数量、两腿时间）。不是全深度、逐笔或每个极值时刻的可成交证据。缺少数量保留 `null`。
- 盘口按小时压缩，50组小批写入；内存待写最多24000条，磁盘不足不无限积压。同格第一次观测在重启重试后保持不变。
- 24H价差汇总在后台每120秒流式读取；每路径至多两个289格数值数组，最多4000路径，不在 HTTP 请求中扫描15天历史。5分钟末值计算分位，分钟极值只用于范围，避免将尖峰过度加权为常态。
- 结算记录只批量读取最近48H，30秒缓存；只取24H价格变化辅助说明，避免页面每5秒查询所有十个涨跌周期。页面只加载所选策略，无上游逐币网络请求。
- API：`GET /api/arbitrage-thinking/simple?strategy=spot|dual|all&notional=1000&hold_hours=72`；`GET /api/arbitrage-thinking/book-history?symbol=...&exchange=Gate&period=24h`。历史接口至多返回最近288个同步快照。均沿用登录保护并禁止响应缓存。
- UI 按等级与状态过滤，30条路径分页，使用已有图标、充提全部链详情和历史弹窗。浏览时保留币与路径顺序，重新排序可主动更新。失败保留记录但撤下当前状态；报价超过10秒时前端独立撤下当前状态。时间统一北京时间。
- 无 MySQL 新表、无账户连接、无交易权限、无真实订单、无新增报警或 Lark。

上线前资源审计：整机磁盘剩余约2.6 GiB，主要空间属于同机其他服务和 MySQL；应用历史约108 MiB（含检查点）。本次不清理其他项目、数据库文件或备份，不修改内存限制。沿用剩余1 GiB拒绝新历史写入的保护；15天是保留上限而非空间不足时保证完整。需由用户另行决定扩容／共享服务存储治理，不能为满足历史保留擅自删除数据。
