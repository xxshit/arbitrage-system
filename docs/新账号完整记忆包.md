## 四、当前待发布的两项核心修改

### 1. COTI动态箱体纠错（`68ce20f`）

用户反馈：COTI连续多日处于同一区间，系统却持续看跌而没有跌。

独立结论：这首先说明旧看跌时点没有兑现，不代表COTI永久看涨。旧逻辑把箱体内短周期转弱、负基差或负资费过度解释成趋势下跌。

本地修正：

- 使用最近24—48小时已收盘30MIN形成动态箱体，分位区间降低极端影线影响。
- 箱体内统一中性；从旧看跌进入箱体时只允许一次“原判断未兑现”纠错，之后静默。
- 向下破位必须有连续两根30MIN收盘低于箱体下沿约0.5%、至少两个周期价格/CVD同向转弱、量能至少约1.15倍，并有多头退出或新空建立的仓位路径。
- 向上突破使用对称标准；不能为了保持推送频率降低条件。
- 同方向突破后，价格相对上次方向推送继续移动约8%才允许再次提醒。

验证边界：当时没有网站登录状态和任意SQL权限，云端COTI实际重复推送条数仍未核验。公开图表只支持“近期拉升后区间消化”的背景，不替代云端推送审计。

### 2. VELVET急涨分类与胜率闭环（`e97620b`）

用户反馈：VELVET两次推送后都急涨，认为捕捉思路正确，要求继续盯盘、分类记录和自行统计胜率。

事实边界：两次“都急涨”尚未取得云端真实推送时间、阶段、触发价格和后续完整K线，因此只记为用户反馈，不能补猜为2胜0负或100%胜率。

本地实现：

- 新增独立 `push_signal_validation`，不与只负责去重的 `lark_push_state`、模拟交易或AKE多周期准确率混算。
- 只在Lark明确返回发送成功后立案。
- 急涨分类按 `5MIN突然点火 / 短线连续加速 / 15MIN极端扩张` 分开统计。
- 从推送后的第一根完整5MIN开始观察60分钟；先到 `+5%` 记命中，先到 `-5%` 记失效。
- 未触线记中性；同根同时覆盖两线或数据缺失记无法判定；这些都不计有效胜率。
- 保存MFE、MAE、首次触线、完整K线数量、触发快照，并在“趋势验证”页面展示各分类胜率和样本构成。
- 全市场5MIN急涨扫描继续覆盖VELVET，不自动扩大“思路分析”长期名单。

本地验证：168项测试、Python编译、JavaScript语法和补丁检查通过。该成绩只说明本地提交当时通过，不代表云端已上线。

## 五、行情判断的核心方法

### 1. 四层记录必须分开

每次分析和文档都显式区分：

- 用户观点：用户提出的观察、机制或方向假设。
- Codex观点：独立判断、异议、竞争路径和置信边界。
- 验证结果：由真实推送记录、完整K线、MySQL或可靠公开数据核验后的事实。
- 被推翻思路：方向、时点、机制或数据口径错误及对应修正。

任何未经验证的用户或Codex判断都不能升级为固定策略知识。

### 2. 用户的“犄角”思路

用户重点观察“价格上涨 + 实际持仓增加 + 多空人数比下降 + CVD上涨”，解释为可能存在较大资金做多、更多账户做空的偏多对手盘结构。这是有价值的候选模型，但不是自动做多结论。

必须保留的反例：

- OI每份合约同时有多空双方，不能单独说明新增方向。
- 多空人数比只描述账户比例，不说明账户规模，不能直接等同“散户/主力”。
- CVD上涨说明主动买入占优，也可能含空头回补，不能单独证明新多建立。
- 做市扩仓、对冲仓增加、低流动性和币价重估都可能制造类似外观。

### 3. 持仓口径

- 优先使用Binance `sumOpenInterest` 的合约数量变化。
- `sumOpenInterestValue` 是USDT名义持仓，会随币价上涨而被动增加，不能直接写成新仓增加。
- 缺数量字段时才近似：`实际仓位数量变化 = (1 + 名义持仓变化) / (1 + 价格变化) - 1`。
- 每条正式判断应在同一个明确周期内同时写价格、实际仓位、人数比、CVD和量能，禁止跨周期拼接因果。

### 4. 基差与资金费

负基差、负资费只描述价格关系和付费方向，不直接说明主力意图。至少并行考虑：

- 空头拥挤与逼空燃料；
- 现货主导拉盘、合约滞后；
- 主动压合约吸引多头或完成换手；
- 高位派发或趋势转弱。

用现货/合约领先关系、量能、实际OI、人数比、CVD、清算和基差收敛方式逐步淘汰路径。正基差、正资费也不能永久保护看涨，只是需要更强反转证据。

### 5. 周期和状态

- 短线：5MIN—30MIN；中线：1H—4H；长线：1D—3D。三档独立，允许方向相反。
- 短周期不能直接推翻中长线；中线多空互换至少连续4次、持续30分钟，与震荡切换至少持续15分钟。
- 趋势阶段：形成前候选 → 点火 → 延续 → 结构失效。早期候选可以宽，正式改口必须慢。
- 旧关键位离开现价约15%后只作复盘背景，实时判断必须用最近已收盘K线动态重新定价。
- 未收盘K线只能形成候选证据，不能在几十秒内制造正式方向反转。

### 6. 推送边界

- 内部候选、一次性机会提醒、持续盯盘是三个独立权限层。
- 普通早期候选只上网页；五根已收盘30MIN强结构可单次提醒；持续盯盘必须由用户明确选择。
- 五根30MIN强结构当前门槛：整体涨幅至少40%、持仓增加、人数比下降、CVD上涨。
- 5MIN急涨默认15%触发，盘中连续两次确认；同一30分钟行情段按点火、加速、极端扩张只允许阶段升级提醒。
- 同方向、同结构、相近数值不重复推送。方向/剧本改变、价格约6%、基差约0.5%、实际持仓约25%或至少两个周期CVD方向变化才可能构成新信息。
