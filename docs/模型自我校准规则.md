# 趋势判断自我校准规则

更新时间：2026-07-28

## 目标

盯盘不是为了证明先前预测正确，而是通过真实行情不断验证、推翻和修正假设。用户思路与我的独立思路都必须接受同一套证据标准。

## 每条思路必须保存

1. 币种、时间和当时价格。
2. 用户的判断与理由。
3. 我的独立判断与理由。
4. 双方共同认可点与明确分歧。
5. 5MIN、15MIN、30MIN、1H、2H、4H关键结构。
6. 主路径、次路径和能够推翻判断的条件。
7. 预期验证周期，避免用短周期波动验证长周期观点。

## 结果分类

- `验证`：方向、时点和核心机制基本正确。
- `部分验证`：方向正确，但时点、路径或关键理由有明显偏差。
- `方向错误`：真实走势与预测方向相反。
- `时点错误`：最终方向正确，但过早入场、过早反手或提醒太迟。
- `条件过严`：像AKE犄角延续漏榜一样，有效结构被硬阈值误杀。
- `条件过松`：插针、旧快照或单一指标造成误触发。
- `数据异常`：接口超时、同名异币、价格错位、清算插针等导致结论不可用。

## 错误原因检查表

- 是否只寻找支持原观点的证据？
- 是否把空头拥挤当成已经发生逼空，把燃料当成点火？
- 是否把负基差、负资费直接等同空头拥挤，而没有检查现货先拉、合约受控、吸引多头或换手等竞争解释？
- 是否把CVD上涨误当成新多建仓，而忽略空头回补？
- 是否忽略持仓数量和名义持仓的口径区别？
- 是否在爆仓后继续使用爆仓前的结构基准？
- 是否用5MIN变化推翻本应由4H验证的观点？
- 是否把单次基差、开差插针当成持续结构？
- 是否忽略成交量对支撑、压力和换手的影响？
- 是否因为希望某个方向成立而降低反证权重？

## 修正规则

1. 错误发生后保留原始判断，不覆盖、不删除。
2. 写清遗漏数据、错误机制和下一次需要增加的验证条件。
3. 单一样本只生成“待验证修正”，避免过拟合。
4. 同类缺陷再次发生时标记为重复缺陷，并提高规则修正优先级。
5. 新规则必须说明它解决什么错误，也必须列出可能误伤什么正常机会。
6. 后续推送若使用修正后的规则，要在复盘中关联原错误案例。

### 已记录错误案例：AKE零轴抖动重复推送

- 类型：`条件过松 + 重复推送`。
- 缺陷：把任何基差跨零都当成重大变化，忽略零轴附近自然抖动。
- 修正：增加两侧最小幅度和总跨度；使用00:44与00:46的真实快照回放验证。
- 举一反三：资金费、基差、开差等所有存在零轴的指标，不能只看符号，必须同时检查幅度、持续性和是否改变原判断。

### 已记录错误案例：SOON/ZAMA抽象过度

- 类型：`机制混淆 + 过度复用`。
- 缺陷：两者都需要观察基差和资费，就共用了同一个趋势方向；忽略SOON仍是正溢价主升，而ZAMA是负基差与偏多犄角并存。
- 修正：共享数据计算，不共享结论；分别维护基准、状态、反证、Lark文案和思路分析。
- 举一反三：同一指标在不同币、不同阶段可能含义相反。负基差在资金结构转弱时可能是换手证据，在偏多犄角完整时也可能只是合约滞后或逼空燃料。

#### ZAMA旧推送的具体错误

- `01:02`与`01:48`的“换手做空确认”均记为方向/时点判断错误，不计为有效机会。
- 缺陷：短周期滞涨权重过高，压过了1H/2H强犄角；负基差被赋予了未经验证的单一含义。
- 修正优先级：中周期趋势结构决定短周期信号属于回调还是反转。5MIN/15MIN只能负责早期预警，不能在1H/2H/4H仍强时单独宣布趋势换手完成。

## 准确性统计

除胜率外，同时记录方向正确率、时点正确率、提前量、最大有利波动、最大不利波动、过早止盈/止损和误推送次数。只有方向、时点与执行价值都合理，才算一次完整的有效判断。

## 未收盘周期导致的观点翻转（2026-07-28）

- 5MIN、15MIN、30MIN滚动窗口在当前K线尚未收盘时可能于几十秒内大幅改变，单次读取只能算候选证据，不能直接推翻上一条完整观点。
- 对换手类盯盘，方向改变至少连续两次完整扫描一致并持续20秒；第二次不一致则自动撤销候选。
- 深基差等同步价格风险可按其自身连续确认机制即时提醒，但必须标记为风险观察，不得等同于趋势方向确认。
- 自我检查：若同一币一分钟内出现方向相反的正式推送，默认视为模型稳定性故障，必须回放两次原始快照并检查未收盘窗口、并发扫描和状态确认层。

### SOON 20:17 做空升级过早

- 错误：浅负基差约 `-0.12%`、资金费仍为正时，仅凭5MIN/15MIN转弱就升级换手做空；后续价格继续上涨且正溢价修复。
- 根因：短周期证据权重过大，没有给1H/2H“价格涨、持仓涨、人数比跌”的核心犄角设置否决权，也没有区分短时贴水与稳定主升破坏。
- 校准：中周期核心犄角仍成立时，CVD不是强制条件，短周期弱化只能预警不能翻转方向；负基差需要持续、加深或传导到资金费，并结合价格破位与持仓/CVD退潮后才能升级。
- 统计：长期换手假设继续记为待验证；20:17阶段升级单独记失败一次，不能用尚未结束的长期假设掩盖短期判断错误。

### COTI负资金面单一叙事重复缺陷（2026-07-30）

- 类型：`机制混淆 + 单一解释`。
- 第一次缺陷：把极负基差、极负资费直接解释为换手后即将下跌。
- 第二次缺陷：修正后又把相同数据直接解释为拥挤空头和逼空燃料。
- 用户补充的竞争机制：主力可能拉高现货并控制合约价格，主动制造负基差、负资费，以吸引多头抬价或完成换手。
- 校准：负基差与负资费只描述价格关系和付费方向，不直接描述主力意图。任何正式判断至少保留三条竞争路径，并写明如何用现货/合约领先关系、量能、OI、人数比、CVD、清算及基差收敛方式证伪。

### COTI趋势验证重复假突破缺陷（2026-07-30）

- 类型：`知识未落地 + 入场确认过松 + 止损结构错误`。
- 已有教训：ACE在7月20日止损后，文档已明确要求突破入场使用5分钟收盘确认。
- 重复错误：COTI计划仍用盘中最高价触线成交；触发K线最高越过入场线但收盘跌回，15分钟后止损。
- 校准：规则文档新增后必须检查代码、数据库状态和页面文案是否同时落实；只写文档不改执行逻辑，不算完成学习闭环。
- 执行规则：未来趋势验证的突破/跌破入场按5分钟收盘确认；止损位置必须检查前序影线、ATR、成交量节点和流动性扫单范围，不能贴着普通波动带。

### 等待入场计划也必须动态证伪（2026-07-30）

- 未成交不等于思路仍然正确。原计划依赖的30MIN/1H结构会随时间、价格和持仓关系变化，禁止无限期等待一个已经失真的开仓价。
- 建单前先比较建议入场位与现价：距离超过`max(2.5%, 2×ATR百分比)`时不创建等待单，继续扫描，直到价格重新接近仍然有效的结构；旧程序遗留且已脱离当前结构的极端远价计划立即撤销。
- 新结构给出相反方向且原计划已观察至少15分钟：撤销旧方向，并按最新结构重新生成计划。
- 等待至少60分钟后，价格沿不利于触发的方向远离入场位超过`max(2.5%, 2×ATR百分比)`：判定入场位背离，撤销旧计划。
- 等待至少45分钟后，即使方向相同，新结构建议入场位与旧入场位偏移超过`max(1.5%, 1.5×ATR百分比)`：判定结构已重新定价，撤销并重建价位。
- 任何基于30MIN/1H的等待计划满4小时必须过期复核；若当前仍有有效信号，可以建立一笔全新的计划，而不是沿用旧止损和旧止盈。
- 撤单不计入胜率或盈亏，但必须保存撤单时间、当时价格、原因和前后思路变化，供后续复盘。

### COTI 10笔验证仅30%胜率的系统性复盘（2026-07-31）

- 样本：COTI已结算10笔，3胜7负，累计约`-8.59U`；盈利合计约`+15.94U`，亏损合计约`-24.53U`。按实际平均盈亏，保本胜率约需40%，30%并不合格。
- 震荡追单：04:55至13:30连续6笔止损，方向在多空之间反复切换。模型把短周期动量变化误认为新趋势，没有要求旧结构完成重置。
- 评分过松：旧门槛52分，仅价格、估算CVD和持仓三项就可能触发；多空分数没有最小差值，弱优势也会被强制定向。
- 做空持仓条件错误：`OI 1H > -0.5%`几乎等于“持仓没有明显下降就给做空加分”，无法证明空头结构，现改为持仓明确增长才可加分。
- 数据名实不符：旧程序所谓CVD由K线收盘位置乘成交量估算，不是真实主动买卖差。现改为Binance K线中的主动买入成交额，按`2×主动买入额-总成交额`计算真实CVD；缺数据时不伪造。
- 忽略已有数据：4H价格和成交量原本已采集，却没有进入评分。现要求4H不过度反向，并把30MIN/1H放量纳入确认。
- 回放顺序偏差：收盘确认入场后，旧逻辑仍使用同一根K线此前的最高/最低价判止盈止损。现从下一根K线才开始计算退出，消除“先出现高点、后确认入场”的未来信息。
- 新执行门槛：方向分至少68，且多空分差至少12；真实CVD、持仓、人数比、放量、4H环境分别作为独立证据。实际平仓后至少等待一根完整30分钟结构，避免止损后立刻反向追单。

### 交易周期必须先于多空方向（2026-07-31）

- 每笔计划先回答“短线还是中长线”，再决定方向、入场、容许回撤、止损、止盈和最长持有时间；禁止只判断多空，不定义周期。
- 短线：以5MIN/15MIN/30MIN及1H结构为主，追求快速验证。入场后60分钟仍未触及第一目标且收盘重新退回入场线的不利一侧，按动能失效退出；最长持有180分钟。触及止盈1后，剩余验证的保护位提高到入场价。
- 短线不得在亏损后改口为中长线，也不能因为舍不得止损而扩大原定风险。
- 中长线：必须先有4H/日线方向、成交量确认过的支撑/阻力区、正常回撤范围和结构失效位；仓位按止损距离反推。没有这些条件时，不建立中长线自动计划。
- 当前自动趋势验证只使用30MIN/1H信号，因此统一标记为短线。已有旧计划维持原规则，防止复盘时篡改；新计划执行短线退出纪律。

### 实时盯盘必须随价格重新定价（2026-08-01）

- 错误样本：AKE现价已经超过`0.004`，推送却仍以早期`0.0020-0.0022`卖墙作为当前判断和关键位，属于行情数据已更新、叙事锚点未更新。
- 历史盘口墙、旧箱体和旧支撑压力只保存为复盘背景；现价距离历史区间超过约15%后，该区间不得继续驱动实时方向、信号键或关键位。
- 当前关键位使用最近已收盘30分钟K线重新计算：近3小时低点形成防守参考，近4小时高点形成突破观察参考；快速拉升后过远的旧高低点自动失效。
- 推送状态键必须描述现价处于“当前支撑带、当前区间上下半部、当前压力带或当前突破”，禁止按某个币的永久绝对价格分桶。
- 如果价格已经大幅离开旧剧本，但资金面没有给出新单边结论，应明确进入“当前区间重新定价/等待确认”，不能用旧故事填补判断空白。

### AKE十分钟内中线翻向复盘（2026-08-02）

- 错误样本：AKE在`14:24:13`显示中线1H-4H偏多，`14:34:13`又显示中线偏空；十分钟只能说明短线结构变化，不能证明1H-4H主趋势已经完成反转。
- 第一条并非干净偏多：价格、持仓和CVD上涨，但多空人数比也上涨，代表追多账户增加，可能是拥挤多头、诱多或主力借反弹布空。旧评分没有充分惩罚这一组合，错误地把价格与CVD的正贡献解释成中线偏多。
- 第二条加入一根新收盘30MIN线后，1H/2H滚动窗口迅速转弱。该数据可以把短线降级，但不应在没有持续确认时直接改写中线。
- 规则修正：中线观点写入MySQL最新盯盘快照并使用迟滞状态。偏多与偏空互换必须连续至少4次扫描、持续不少于30分钟；偏多/偏空与震荡互换至少持续15分钟。候选阶段仍显示原中线，并注明新方向尚在确认。
- 方向标题明确标记为“短线方向”，允许短线先变化；中线独立显示，禁止用短线翻转冒充中线翻转。
- 工程错误：本地已经修复历史价位，但云端仍运行旧文件，导致`0.0020-0.0022`继续出现在8月2日推送。以后完成影响线上行为的修复后，必须同时核对Git版本、云端文件、运行进程和实际推送模板，不能把“已推送GitHub”当成“已部署”。

### AKE 20:40—20:55 追涨杀跌式改口复盘（2026-08-02）

- 用户指出：系统最重要的能力应是发现趋势形成，而不是等行情走出一段后再追认；AKE在20:40、20:50、20:55先偏多、再转为等待/转弱、又恢复偏多，说明模型在追逐噪声。
- 数据回放：三次推送的持仓、人数比、CVD和主要价格结构没有发生足以解释趋势反转的变化；基差仅在约`+0.004% → -0.099% → +0.004%`之间摆动。20:50实际属于证据不足，不是新的空头趋势。
- 根因一：AKE方向函数把基差是否大于零当成硬开关，零轴附近微小变化就能让偏多结构掉入“新区间等待”，而方向名变化又绕过四小时重复抑制。
- 根因二：只要一个窗口出现持仓下降、人数比上升，就可能被升级为主力平多；单根或单周期证据权重过高。
- 修正：基差`-0.10%—+0.10%`、资费`-0.005%—+0.005%`视为中性噪声带；中性/证据不足不形成Lark方向推送。主力平多需至少两个窗口同时出现持仓下降与人数比回升，正式多空方向改变需连续至少三次观察并持续十分钟。
- 方法修正：系统输出分成“形成前候选、点火、延续、结构失效”。候选可以早，但必须明确未确认；已确认趋势不能由单根短周期线或单个资金指标直接推翻。
