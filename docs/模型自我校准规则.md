# 趋势判断自我校准规则

更新时间：2026-07-28

## 目标

盯盘不是为了证明先前预测正确，而是通过真实行情不断验证、推翻和修正假设。用户思路与我的独立思路都必须接受同一套证据标准。

## 每条思路必须保存

1. 币种、时间和当时价格。
2. 用户的判断与理由。
3. 我的独立判断与理由。
4. 双方共同认可点与明确分歧。
5. 5MIN、15MIN、30MIN、1H、2H、4H关键结构。
6. 主路径、次路径和能够推翻判断的条件。
7. 预期验证周期，避免用短周期波动验证长周期观点。

## 结果分类

- `验证`：方向、时点和核心机制基本正确。
- `部分验证`：方向正确，但时点、路径或关键理由有明显偏差。
- `方向错误`：真实走势与预测方向相反。
- `时点错误`：最终方向正确，但过早入场、过早反手或提醒太迟。
- `条件过严`：像AKE犄角延续漏榜一样，有效结构被硬阈值误杀。
- `条件过松`：插针、旧快照或单一指标造成误触发。
- `数据异常`：接口超时、同名异币、价格错位、清算插针等导致结论不可用。

## 错误原因检查表

- 是否只寻找支持原观点的证据？
- 是否把空头拥挤当成已经发生逼空，把燃料当成点火？
- 是否把CVD上涨误当成新多建仓，而忽略空头回补？
- 是否忽略持仓数量和名义持仓的口径区别？
- 是否在爆仓后继续使用爆仓前的结构基准？
- 是否用5MIN变化推翻本应由4H验证的观点？
- 是否把单次基差、开差插针当成持续结构？
- 是否忽略成交量对支撑、压力和换手的影响？
- 是否因为希望某个方向成立而降低反证权重？

## 修正规则

1. 错误发生后保留原始判断，不覆盖、不删除。
2. 写清遗漏数据、错误机制和下一次需要增加的验证条件。
3. 单一样本只生成“待验证修正”，避免过拟合。
4. 同类缺陷再次发生时标记为重复缺陷，并提高规则修正优先级。
5. 新规则必须说明它解决什么错误，也必须列出可能误伤什么正常机会。
6. 后续推送若使用修正后的规则，要在复盘中关联原错误案例。

### 已记录错误案例：AKE零轴抖动重复推送

- 类型：`条件过松 + 重复推送`。
- 缺陷：把任何基差跨零都当成重大变化，忽略零轴附近自然抖动。
- 修正：增加两侧最小幅度和总跨度；使用00:44与00:46的真实快照回放验证。
- 举一反三：资金费、基差、开差等所有存在零轴的指标，不能只看符号，必须同时检查幅度、持续性和是否改变原判断。

### 已记录错误案例：SOON/ZAMA抽象过度

- 类型：`机制混淆 + 过度复用`。
- 缺陷：两者都需要观察基差和资费，就共用了同一个趋势方向；忽略SOON仍是正溢价主升，而ZAMA是负基差与偏多犄角并存。
- 修正：共享数据计算，不共享结论；分别维护基准、状态、反证、Lark文案和思路分析。
- 举一反三：同一指标在不同币、不同阶段可能含义相反。负基差在资金结构转弱时可能是换手证据，在偏多犄角完整时也可能只是合约滞后或逼空燃料。

#### ZAMA旧推送的具体错误

- `01:02`与`01:48`的“换手做空确认”均记为方向/时点判断错误，不计为有效机会。
- 缺陷：短周期滞涨权重过高，压过了1H/2H强犄角；负基差被赋予了未经验证的单一含义。
- 修正优先级：中周期趋势结构决定短周期信号属于回调还是反转。5MIN/15MIN只能负责早期预警，不能在1H/2H/4H仍强时单独宣布趋势换手完成。

## 准确性统计

除胜率外，同时记录方向正确率、时点正确率、提前量、最大有利波动、最大不利波动、过早止盈/止损和误推送次数。只有方向、时点与执行价值都合理，才算一次完整的有效判断。
