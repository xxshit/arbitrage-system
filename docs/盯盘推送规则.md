# 盯盘推送规则

更新时间：2026-08-04

## HEI 基差、量能与 5MIN 快速风险盯盘（2026-08-06）

- 用户明确授权 HEI 进入持续重点盯盘。链上地址向交易所转币只记录为用户风险假设，系统不把地址归属、转账目的或“主力已出货”写成已验证事实。
- HEI 启用时由独立 30 秒任务复核，重点读取 BN 基差、5MIN/15MIN 涨跌、成交量倍数与 CVD，同时保留 30MIN 的持仓和人数比背景。
- 价格阈值：5MIN `≤-3%` 或 `≥+4%`；15MIN `≤-7%` 或 `≥+7%`。量能阈值：5MIN/15MIN 达近期均值 `2.5x`，并按 CVD 方向区分主动买入和主动卖出。
- 基差阈值：绝对值达到 `0.30%` 后进入异常区，再按 `0.60%/1.00%/2.00%` 分区。正溢价与负贴水都提醒，但解释不同，不能机械等同出货。
- 同一根 5MIN K线同类信号只推一次；基差只有进入新深度区或方向改变才再次推送。实时数据不完整时静默，不用旧 MySQL 快照生成新风险消息。

## 5MIN 突然点火独立提醒（2026-08-04）

- 用户观察样本：CYS 在约15分钟内累计上涨超过50%，其中连续两根5MIN涨幅均超过20%。这类行情在“五根30MIN强犄角”完成前已经发生明显点火，原30分钟链路发现过晚。
- 新增独立全市场轻量扫描：单根5MIN涨幅达到 `15%` 即进入候选。当前尚未收盘的5MIN必须连续两次观察仍超过阈值，过滤瞬时插针；已经收盘的5MIN可直接确认。
- MySQL 5分钟价格桶只负责全市场初筛；只有超过候选阈值的币才请求 Binance K线、持仓、多空人数比与成交数据，避免对全市场逐币高频请求。
- 推送分为 `5MIN突然点火 → 短线连续加速 → 15MIN极端扩张`。15MIN累计达到50%或最近三根中至少两根5MIN达到急涨阈值，进入极端扩张阶段。
- 同一30分钟行情段内，同一阶段只推送一次；只有阶段升级才再次提醒。它是突然启动提醒，不自动加入持续盯盘，也不等于无条件追多。
- 持仓增加、人数比下降和CVD上涨用于提高趋势可信度，但不是本条价格急涨提醒的硬门槛；若资金结构未共振，推送必须明确写出“尚未形成完整犄角”和高位换手风险。

## 通用盯盘币同结构去重

这条规则不只针对 AKE。后续所有放入“思路分析 / 重点盯盘”的币，都走同一套 Lark 推送逻辑。

### 核心原则

- 页面和数据库可以每 5 分钟正常刷新；
- Lark 只在出现新结构、新证据、新方向时推送；
- 如果方向、价格区间、判断剧本都没变，价格、持仓、CVD、盘口墙只是小幅抖动，不重复打扰；
- 机会来了仍然要立刻提醒，不设置机械冷却时间。

### 什么算新信息

- 方向或剧本改变；
- 价格较上次推送变化约 `6%` 以上；
- Binance 基差变化约 `0.5%` 以上；
- 资金费变号，或资金费大幅变化；
- 持仓较上次推送变化约 `25%` 以上；
- 盘口墙规模变化约 `80%` 以上；
- 30M / 1H / 2H 至少两个周期的 CVD 方向发生改变。

### 目标

机会来了立刻叫醒；没有新证据时安静盯盘。避免同一个结构、同一个判断、相近数值每 5 分钟重复推送，把真正重要的新变化淹没。

## 资金面结构优先级：不能只看 CVD 或价格区间

更新时间：2026-07-24

趋势推送必须同时解释以下四类数据，不能用单一指标认死理：

- 价格位置 / 新旧区间；
- 持仓变化；
- 多空人数比变化；
- CVD / 主动成交；
- 资金费与基差。

重点新增规则：

1. `CVD上涨` 只能说明近端主动买入较多，不能单独等同于主力继续做多。
2. 如果出现 `持仓下降 + 多空人数比上升`，资金面解释优先按“散户平空、主力平多”处理。高位币遇到这种结构，要判定为看涨减弱或高位换手观察。
3. 如果同时出现 `资费转负`、`基差转负`，说明合约端多头支撑继续削弱，不能继续按“正资费+正基差拉高合约”的旧剧本看。
4. 如果 `持仓上升 + 多空人数比下降 + CVD上涨`，才是更健康的主力做多/散户做空结构；这类结构可以提高看涨评分。
5. 如果 `持仓下降 + 多空人数比下降`，要理解为散户平多、主力平空，偏向空头获利了结，不一定是继续下跌。

所以以后 AKE、US、TLM 等思路推送，必须写清楚：当前看涨信息是在增强还是减弱，以及是哪一类资金面结构导致的判断变化。

### AKE 与 ERA / 2026-07-27 / 分阶段盯盘规则

- AKE 当前不能只看价格抗跌。若价格仍在高位，但1H、2H和4H持仓同步下降、CVD走弱，优先标记为“价格抗跌、仓位撤退”。这可能是空头回补、存量多单退出或低持仓控盘，不能直接等同于健康上涨。
- AKE 重新增强必须看到清算后新仓重建：价格不破新结构低点，持仓停止下降并重新增加，CVD在没有新增巨额爆仓时继续走高。若反抽时持仓仍下降、量能萎缩或价格跌破清算后结构低点，则按换手派发/转弱提高权重。
- ERA 采用两段式盯盘，不把“可能逼空”一次性写成趋势反转：
  1. `反抽萌芽`：价格离开约0.0714低点区，5MIN/15MIN/30MIN中至少两个周期价格与CVD改善，持仓没有同步明显流失；先提醒逼空燃料开始点火。
  2. `逼空确认`：价格放量站上约0.0726，至少两个短周期价格与CVD共振转强，持仓保持或增加、人数比继续受压；第一观察带为0.0732-0.0738。
  3. `诱多结束观察`：价格进入0.0732以上后滞涨，5MIN/15MIN CVD转弱，同时持仓回落、人数比回升或出现异常放量；此时才提醒反弹可能结束并重新验证下跌。
- ERA 若上涨伴随持仓快速下降，优先解释为空头回补，持续性低于“价格上涨+持仓增加”；若跌回0.0714下方且CVD继续为负，则反抽假设失效。
- 所有阶段信号只在实时数据完整时生成；交易所请求失败、退回数据库旧快照时，不得因旧价格单独生成新的阶段判断。

### SOON 与 ZAMA / 2026-07-28 / 主升后换手做空监控

- 用户修正：资金费低于 `-1%` 不是硬性条件。主力开始换手时，通常是基差先转负，资金费再慢慢跟随基差下移；因此监控必须以基差为先行信号，同时持续观察币价、CVD、持仓、人数比和成交量。
- 三阶段模型：`基差连续两次30秒快照为负`立即进入换手观察；`资费随后跟随转负`升级为换手增强；负基差后再出现价格滞涨、CVD转弱，并伴随持仓退出、人数比追多或异常放量之一，升级为“换手转弱/做空确认观察”。
- 资金费是否低于-1%只代表负资费深度，不决定能否开空。负资费越深，空头付费越高，也越可能形成逼空燃料。
- 若基差转负期间价格继续放量创新高、CVD上涨且持仓同步增长，优先按暂时贴水或逼空延续处理；只有价格跌破近端结构低点且反抽无法收回，做空确认度才提高。
- 完整结构按5分钟更新；另设30秒轻量检查，同时读取SOON与ZAMA的Binance标记价、指数价和资金费。基差连续两次为负才触发完整分析，过滤单点插针，不调用语言模型、不消耗对话TOKEN。
- 防重复按“基差深度区间 + 资费是否跟随 + 结构是否确认”判断；只有阶段改变、基差进入更深区间或方向升级才重新提醒。

### SOON与ZAMA必须分开解释（2026-07-28）

- 共享的只有数据采集与连续两次负基差防插针机制，趋势假设、状态机、推送方向和文案全部分开。
- SOON基准：此前持续正基差、正资费。重点监控“正溢价主升何时被破坏”：基差稳定转负是第一层，资费跟随转负是第二层，价格滞涨、CVD转弱和仓位换手才是做空确认层。
- ZAMA基准：基差已经稳定为负，但资费仍接近正值，同时中周期存在价格上涨、持仓增加、人数比下降、CVD上涨的偏多犄角。当前应先识别为“负基差与偏多犄角背离”，不能复制SOON的正溢价破坏结论。
- ZAMA若负基差存在但偏多犄角延续，优先防继续拉升/逼空；只有CVD转弱、持仓退出、人数比追多或异常放量并跌破近端结构，才升级换手做空。
- 后续加入同类币也必须先建立自身基准，不得仅因都出现负基差就套用同一个剧本。

### ZAMA深负基差分级（2026-07-28）

- ZAMA使用5秒同步快照，连续两次才确认，避免把单点插针当成换手信号；SOON保持自身30秒监控，不混用节奏与结论。
- 基差进入 `-0.5% / -1% / -2%` 新区间才构成新的阶段信息；同一区间内的小幅波动不重复推送。
- 到 `-1%` 后在MySQL建立基差打开记录，绝对值每扩大 `0.2%` 追加一次扩展记录，并保存近期最大值及时间。
- 到 `-2%` 后提升为深负基差换手观察；资费跟负是增强证据，但没有固定负资费硬门槛。
- 深负基差仍必须与放量、价格滞涨/跌破、CVD转弱、持仓退出和人数比变化联合判断；偏多犄角未破坏时不得机械追空。

### SOON/ZAMA同方向基差区间防重复（2026-07-28）

- 错误样本：ZAMA在 `03:00:48` 与 `03:05:23` 连续推送 `zama_turnover_short_ready`。两条判断、标题、关键位和主要周期结构一致，第二条只是价格约 `0.06283 → 0.06218`、基差约 `-0.2040% → -0.0235%`。
- 根因：旧逻辑把基差区间的任何变化都视为新观点，错误地把“深负基差向零轴修复”也当成风险升级，从而绕过4小时重复抑制。
- 修正：SOON/ZAMA在方向和判断不变时，基差只有在绝对值较上次推送继续扩大至少 `0.2%` 才可提前再次推送；绝对值缩小或仅跨回较浅区间一律静默。
- 同方向仍可提前推送的真正新信息包括：有效资金费正负翻转、价格变化达到约 `6%`、持仓变化达到约 `25%`，或至少两个观察周期的CVD方向改变。
- 方向真正改变仍可立即推送；同方向且无上述新信息，至少4小时内不得重复。该规则同时适用于以后加入的所有基差换手型重点币。

### 换手观点方向切换二次确认（2026-07-28）

- 问题样本：ZAMA在 `03:00:09` 推送“负基差独立观察”，仅39秒后又推送“犄角破坏/换手做空观察”。这不是合理的观点演进，而是未收盘滚动窗口抖动造成的过早改判。
- 原始差异：第一条30MIN CVD约 `+155K`、5MIN CVD约 `+1.9K`；第二条5/15/30MIN CVD迅速变为约 `-308K / -379K / -70K`，价格约 `0.06346 → 0.06283`。1H/2H持仓和人数比几乎未变，说明新空头结论主要来自几十秒内的短周期数据变化。
- 修正：SOON/ZAMA除已由5秒同步基差连续确认的 `-2%` 深基差风险外，任何观点方向改变都必须经过至少两次独立完整结构扫描，方向一致且持续不少于20秒才可推送。
- 执行频率：只对SOON/ZAMA每30秒做一次完整结构复核，不高频扫描其它重点币；因此新方向正常约30秒可确认，又不会因每5秒噪声来回改口。
- 若第二次扫描恢复原方向，候选方向立即作废并静默。方向候选不写成事实，只有确认后才进入Lark推送和正式判断记录。

### 分周期方向表达（2026-07-28）

- 禁止只写笼统的“看涨”或“看跌”。每次正式思路推送必须同时给出：短线 `5MIN-30MIN`、中线 `1H-4H`、长线 `1D-3D` 三档方向。
- 三档方向独立计算，允许出现“短线偏多、中线震荡、长线偏空”。存在多空冲突时必须明确提示“周期方向相反”，禁止用短线反弹替代长期反转，也禁止用长期看空否认短线逼空机会。
- 短线结合价格、CVD、持仓、人数比和量能；中线强调1H/2H/4H结构是否共振；长线主要看1D/3D价格结构，资金费和基差只作辅助，证据不足时写“未确认”。
- “长期”不允许由几根5分钟线推导。当前系统的自动长期栏上限为3D；超过3D的叙事、解锁、筹码和项目面判断必须单独标注，不与短线技术结构混写。

### 我的独立判断与错误复盘要求

- 每次推送不仅复述用户思路，还必须给出我的独立观点；有分歧时明确写出分歧和证据，不用模糊措辞掩盖。
- 每个观点必须携带可被证伪的条件。后续走势触发反证时，优先推送“原判断失效/观点修正”，不能继续换一种说法维护旧结论。
- 复盘至少区分：判断正确、部分正确、方向错误、时点错误、条件过严、条件过松、数据异常七类；记录遗漏的数据和修正办法。
- 修正后的规则从下一轮盯盘开始使用，同时保留旧判断、当时数据和错误原因，以便统计同类错误是否再次发生。
- 不以频繁改变观点冒充聪明。只有出现新证据、反证或周期结构切换才改判；没有新信息时继续安静观察。

### 基差/资费零轴抖动去重（2026-07-28）

- 问题样本：AKE在 `00:44:25` 与 `00:46:55` 连续推送。两次方向、信号区间、价格、持仓和30MIN/1H/2H结构几乎完全一致，唯一触发原因是基差从约 `-0.0415%` 抖到 `+0.1022%`，旧逻辑把任何跨零都当成重大翻转。
- 通用修正：基差正负翻转必须跨过零轴死区，前后绝对值均至少约 `0.10%`，且总变化至少约 `0.30%`，才视为值得打扰的新叙事；零轴附近的小幅来回不再推送。
- 资费正负翻转同样设置有效跨度：前后绝对值均至少约 `0.005%`，总变化至少约 `0.02%`，避免最低资费附近的符号抖动制造重复消息。
- SOON/ZAMA不受误伤：它们的换手模型使用独立的30秒连续确认，基差连续两次为负会改变阶段并提醒，不依赖通用“正负翻转”判定。
- 外部任务触发全量扫描时，不能因此把其它币的微小数值变化当成新观点；方向、信号区间和核心结构未改变时继续静默。

### 历史价位失效与动态重新定价（2026-08-01）

- 推送生成前必须检查判断中的价格锚是否仍靠近现价。现价已明显离开旧墙、旧箱体或旧关键位时，旧价位只能作为复盘背景，不能出现在当前标题、判断和关键位中。
- 当前关键位优先取最近已收盘K线结构；防守与突破区间必须围绕现价可交易范围。过远的历史低点或高点自动剔除。
- 信号去重使用当前结构位置，而不是永久绝对价格档。重新定价本身可以构成一次新观点；重新定价后若结构和观点没有继续变化，仍执行4小时重复抑制。
- 此规则适用于所有思路盯盘币，不只适用于AKE。币种专属剧本必须带失效条件，不能永久覆盖通用实时结构。

### 中线方向迟滞与短中线分离（2026-08-02）

- 推送最上方的方向明确为“短线方向”，5MIN-30MIN证据变化后可以较快调整。
- 中线1H-4H采用持久化状态，不随单根新30MIN线立即翻向。偏多与偏空互换至少持续30分钟且连续4次扫描一致；与震荡/分歧之间切换至少持续15分钟。
- 候选方向确认期间仍展示原中线观点，并注明候选方向，不把候选写成事实。
- `价格上涨 + 持仓上涨 + 多空人数比上涨`不是健康偏多犄角。即使CVD上涨，也要按追多拥挤/诱多/主力借势布空的竞争路径扣分，不能直接显示干净中线偏多。
- 每次线上推送逻辑修改后必须检查云端实际文件不再包含已失效模板，并确认Gunicorn只有一个主进程及其正常工作进程。

### 趋势形成优先与四阶段状态（2026-08-02）

- 趋势筛选优先发现“形成前候选”，不再把已经大涨后的动量确认当成唯一入口。30MIN扫描仍每半小时在收线后执行，避免用未收盘K线制造虚假早期信号。
- 四阶段依次为：`形成前候选 → 点火 → 延续 → 结构失效`。允许候选消失，但已经形成的正式方向不得因一根短线或一个指标抖动直接跨级反转。
- 形成前候选以“价格仍未明显扩张、持仓开始增加、人数比下降”为核心；CVD上涨提高确定性，但不是硬条件，CVD尚未确认时必须显式降低置信度。
- AKE等正式盯盘币：基差在`±0.10%`内、资费在`±0.005%`内属于零轴噪声。证据不足、新区间等待和噪声修复只更新网页，不发送方向消息。
- 多空方向改变至少连续三次结构观察并持续十分钟；中线1H-4H仍执行更严格的30分钟迟滞。早发现与慢改口分别处理，不能互相替代。
- 普通形成前候选只显示在日报趋势网页，不推送、不自动加入“思路分析/盯盘名单”。盯盘名单只能由用户明确加入或在网页手动加入。
- 全市场扫描只有满足用户原先严格定义的“最近5根30MIN整体强涨、同期持仓上涨、人数比下降、CVD上涨”的强犄角结构，才允许独立推送一次；即使推送，也不自动变成持续盯盘币。

### 持仓口径与动态资金结构叙事（2026-08-04）

- 推送中的 Binance `sumOpenInterestValue` 是按 USDT 计价的名义持仓，币价本身上涨会抬高该数值，不能直接解释为新增仓位。
- 主判断优先使用 Binance `sumOpenInterest` 的合约数量变化。若该字段临时缺失，才使用近似公式：`实际仓位数量变化 = (1 + 名义持仓变化) / (1 + 价格变化) - 1`。例如币价和名义持仓都上涨100%，估算实际仓位数量为0%，不能写成持仓翻倍。
- 每条思路推送必须明确引用一个有效观察周期，并同时写出：该周期价格变化、名义持仓变化、实际仓位数量变化和多空人数比变化。禁止把不同周期的数据拼成同一句因果判断。
- 人数比上涨只表示账户结构相对向多头倾斜，可能是小账户追多，也可能是空头账户退出更快；人数比下跌同理。它描述账户比例，不直接证明主力方向，必须与实际仓位数量及价格联合解释。
- 资金结构先形成主判断，CVD后加入：CVD与主判断同向时增强趋势强度，反向时降低确定性并保留竞争路径，不能由CVD单独覆盖仓位和人数比证据。
- AKE及以后所有盯盘币不得复用固定结论句。文案必须依据当次最有信息量的30MIN/1H/2H窗口组织，说明仓位究竟在增加、退出还是仅被币价重估；没有新结构或新观点时继续静默。
