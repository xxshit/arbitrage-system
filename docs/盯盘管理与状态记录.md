# 盯盘管理与状态记录

更新时间：2026-07-28

## 功能位置

- 页面位置：`日报 → 思路分析 → 盯盘管理`。
- 运行中的币显示开始时间、开始价格、当前价格、开始后的涨跌、数据库价格记录内的最高/最低、最近一次Lark推送和盯盘时长。
- 点击“停止盯盘”后，币种立即退出后台完整结构扫描和Lark思路推送，但历史思路、推送记录和走势保留在“已停止盯盘”中。
- 已停止币可以点击“重新盯盘”；重新开始时会以当时价格和时间建立新一轮盯盘基准。

## MySQL记录

- 表：`thought_watch`。
- 关键字段：`symbol`、`active`、`started_at`、`start_price`、`stopped_at`、`stop_price`、`note`、`updated_at`。
- 状态以MySQL为准，不再依赖只存在于Python代码中的硬编码名单；电脑或网站重启后仍能保持停止/运行状态。

## 当前状态

- 运行中：`AKE/USDT`、`T/USDT`、`ERA/USDT`、`SOON/USDT`、`ZAMA/USDT`。
- 已停止：`US/USDT`。按用户要求停止后，不再参与自动盯盘或Lark趋势分析推送。

## 数据说明

- “开始后涨跌”使用盯盘开始价格与当前价计算。
- “记录最高/最低”来自本地 `futures_price_history`。该表采用滚动保留，因此较早开始的币展示的是数据库当前保留区间内的最高/最低，不冒充完整历史极值。
- 思路历史与是否继续盯盘分离：停止盯盘不会删除过去的判断、错误复盘和胜率记录。
