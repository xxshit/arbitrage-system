# 盯盘管理与状态记录

更新时间：2026-08-07

## 功能位置

- 页面位置：`日报 → 思路分析 → 盯盘管理`。
- 运行中的币显示开始时间、开始价格、当前价格、开始后的涨跌、数据库价格记录内的最高/最低、最近一次Lark推送和盯盘时长。
- 点击“停止盯盘”后，币种立即退出后台完整结构扫描和Lark思路推送，但历史思路、推送记录和走势保留在“已停止盯盘”中。
- 已停止币可以点击“重新盯盘”；重新开始时会以当时价格和时间建立新一轮盯盘基准。

## MySQL记录

- 表：`thought_watch`。
- 关键字段：`symbol`、`active`、`started_at`、`start_price`、`stopped_at`、`stop_price`、`note`、`updated_at`。
- 状态以MySQL为准，不再依赖只存在于Python代码中的硬编码名单；电脑或网站重启后仍能保持停止/运行状态。

## 当前状态

- 云端 MySQL 运行中：`AKE/USDT`、`BTW/USDT`、`COTI/USDT`、`ERA/USDT`、`SOON/USDT`；后续仍以网页和 MySQL 实时状态为准。
- `HEI/USDT` 已于 2026-08-07 按用户要求停止重点盯盘和推送。停止后退出通用结构扫描与 30 秒快速风险扫描的实际行情请求，历史思路、快照和推送审计记录继续保留。
- `TLM/USDT`、`US/USDT`、`T/USDT`、`ZAMA/USDT` 及页面中其他已停止币不再参与自动盯盘或 Lark 趋势分析推送。

## 数据说明

- “开始后涨跌”使用盯盘开始价格与当前价计算。
- “记录最高/最低”来自本地 `futures_price_history`。该表采用滚动保留，因此较早开始的币展示的是数据库当前保留区间内的最高/最低，不冒充完整历史极值。
- 思路历史与是否继续盯盘分离：停止盯盘不会删除过去的判断、错误复盘和胜率记录。

## 网页自主加入盯盘（2026-07-28）

- 在 `日报 → 思路分析 → 盯盘管理` 顶部输入币种简称或交易对，例如 `BTC`、`BTCUSDT`、`BTC/USDT`，选择建议项后点击“开始盯盘”。
- 系统先校验 Binance USDT 永续合约是否存在，成功后把开始时间、开始价格和运行状态写入 `thought_watch`；已有但已停止的币会以当前时间和价格开启新一轮记录。
- 网页加入的币不依赖 Python 硬编码名单。后台每5分钟读取价格、持仓、多空人数比、CVD和成交量，只有形成新的确定性结构、方向变化或重要反证时才使用思路机器人推送。
- 停止与重新盯盘仍使用同一张卡片，历史记录不会因停止或重启网站而删除。
