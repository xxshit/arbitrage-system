# 账号与邀请码管理

## 权限边界

- `admin`：可以查看“账号管理”索引、生成邀请码、查看邀请码使用记录和账号活动时间。
- `viewer`：只能查看业务页面；服务端不会渲染“账号管理”入口，访问管理接口会返回 `403`。
- 邀请码和账号数据保存在 MySQL，页面只通过管理员鉴权后的接口读取。

## 一次性邀请码

1. 管理员在左侧进入“账号管理”，点击“生成邀请码”。
2. 新邀请码默认 7 天有效，只能成功注册一个账号。
3. 注册时通过条件更新原子占用邀请码；并发提交同一个邀请码时，只允许一个请求成功。
4. 注册成功后，系统记录使用账号和使用时间，并清除数据库中的完整邀请码，只保留哈希与前缀用于核对。
5. 未使用且未过期的新邀请码会在管理员页面显示完整值并支持复制。
6. 升级前创建的历史邀请码只保存了哈希，无法逆向恢复完整内容；页面会标明“历史邀请码仅保留前缀”，需要时重新生成。

## 加密设备绑定

- 每个账号分别保留一个电脑端槽位和一个手机端槽位，两端可以同时在线；同一槽位只允许一份有效会话。
- 浏览器或主屏 Web App 首次使用时在 IndexedDB 生成 ECDSA P-256 设备密钥。私钥设置为不可导出且只留在当前浏览器资料中，MySQL 只保存公钥、短指纹和会话摘要。
- 登录必须同时通过密码和随机挑战签名。某类设备已经绑定后，其他设备即使密码正确也会被拒绝，原设备会话不受影响；管理员会在左侧“安全通知”看到被拦截设备的短指纹、类型、客户端说明和时间。
- 管理员可以在账号信息下查看电脑端、手机端绑定并单独解除。解除后旧设备会话立即失效，该槽位下一次登录可重新绑定。
- 封禁账号或重置密码会让电脑、手机会话同时失效，但不会自动解除设备绑定；再次登录仍必须使用原绑定设备。

这里的“设备指纹”是当前浏览器/PWA持有的加密身份，不是硬件序列号。换浏览器、清除网站数据或重装主屏网页会丢失本地私钥，需要管理员核实本人后解除旧绑定再重新绑定。首次绑定本身必须在可信设备上完成；它不能证明正在操作电脑的人一定是账号本人，也不能替代密码保管和系统账号保护。

## 正式短域名

当前 `sslip.io` 地址是无需购买域名即可启用 HTTPS 的临时公网地址，因此会包含服务器 IP 和独立端口。若要使用类似 `arbi.example.com` 的短网址，需要准备一个自有域名并完成 DNS 解析；随后在 Nginx 和证书配置中替换域名即可，网站和 MySQL 数据无需迁移。
